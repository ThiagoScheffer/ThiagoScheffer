# 🚀 Selected Projects

## Gestor Pro

**React • TypeScript • PostgreSQL • Supabase • Hono • AI**

A service-operations platform developed from an earlier C# solution into a modern multi-user web application supporting approximately **200 users**.

Key engineering work includes:

* React and TypeScript frontend
* Supabase PostgreSQL, Authentication and Realtime
* Authenticated Hono API routes running server-side
* PostgreSQL Row Level Security
* Server-side AI integration using Gemini
* Zod validation for AI and application data
* Automated Excel, Word and PDF document generation
* Customer-scoped data access
* Transaction-sensitive operations through database RPCs
* AI features designed as controlled assistance rather than autonomous business actions

One automated reporting workflow reduced approximately **4–8 hours of manual preparation and review to around 1 hour**.

> The full operational platform is private because it contains client and operational data. A public demonstration version is available through my portfolio.
